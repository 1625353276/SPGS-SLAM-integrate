# SPGS-SLAM 配置文件参数详解

本文档详细说明 SPGS-SLAM 项目中所有配置文件的参数含义。

---

## 一、ORB_SLAM3 配置文件

ORB_SLAM3 配置文件控制视觉里程计和 SLAM 系统的行为。

### 1.1 系统配置

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `System.LoadAtlasFromFile` | string | - | 从指定文件加载之前的地图会话。如果文件不存在，系统会创建新地图 |
| `System.SaveAtlasToFile` | string | - | 将当前会话保存到指定文件。如果文件已存在会被覆盖 |

### 1.2 相机参数

#### 基本相机模型
| 参数 | 类型 | 示例值 | 说明 |
|------|------|--------|------|
| `File.version` | string | "1.0" | 配置文件版本号 |
| `Camera.type` | string | "PinHole" | 相机模型类型。可选：`PinHole`, `KannalaBrandt8`, `Rectified` |

#### 左相机内参 (Camera1)
| 参数 | 类型 | 示例值 | 说明 |
|------|------|--------|------|
| `Camera1.fx` | float | 458.654 | 左相机 x 方向焦距 (像素) |
| `Camera1.fy` | float | 457.296 | 左相机 y 方向焦距 (像素) |
| `Camera1.cx` | float | 367.215 | 左相机光心 x 坐标 (像素) |
| `Camera1.cy` | float | 248.375 | 左相机光心 y 坐标 (像素) |
| `Camera1.k1` | float | -0.28340811 | 左相机径向畸变系数 1 |
| `Camera1.k2` | float | 0.07395907 | 左相机径向畸变系数 2 |
| `Camera1.p1` | float | 0.00019359 | 左相机切向畸变系数 1 |
| `Camera1.p2` | float | 1.76187114e-05 | 左相机切向畸变系数 2 |

#### 右相机内参 (Camera2)
| 参数 | 类型 | 示例值 | 说明 |
|------|------|--------|------|
| `Camera2.fx` | float | 457.587 | 右相机 x 方向焦距 |
| `Camera2.fy` | float | 456.134 | 右相机 y 方向焦距 |
| `Camera2.cx` | float | 379.999 | 右相机光心 x 坐标 |
| `Camera2.cy` | float | 255.238 | 右相机光心 y 坐标 |
| `Camera2.k1/k2/p1/p2` | float | - | 右相机畸变系数 (同左相机) |

#### 通用相机参数
| 参数 | 类型 | 示例值 | 说明 |
|------|------|--------|------|
| `Camera.width` | int | 752 | 图像宽度 (像素) |
| `Camera.height` | int | 480 | 图像高度 (像素) |
| `Camera.fps` | float | 10.0 | 相机帧率 (FPS)，影响帧间时间计算 |
| `Camera.RGB` | int | 1 | 颜色顺序：0=BGR, 1=RGB。对灰度图像无效 |

### 1.3 立体视觉参数

| 参数 | 类型 | 示例值 | 说明 |
|------|------|--------|------|
| `Stereo.ThDepth` | float | 60.0 | 深度阈值 (米)。超过此值的点被视为远点，仅用于姿态估计而不用于建图 |
| `Stereo.T_c1_c2` | matrix | 4x4 | 左相机到右相机的刚体变换矩阵。包含旋转和平移，用于计算视差和深度 |

**变换矩阵格式：**
```yaml
Stereo.T_c1_c2: !!opencv-matrix
  rows: 4
  cols: 4
  dt: f
  data: [R11, R12, R13, tx,
         R21, R22, R23, ty,
         R31, R32, R33, tz,
         0,   0,   0,   1]
```

### 1.4 IMU 参数

#### IMU 外参
| 参数 | 类型 | 说明 |
|------|------|------|
| `IMU.T_b_c1` | matrix | IMU 坐标系到左相机坐标系的变换矩阵 (4x4) |

#### IMU 噪声参数
| 参数 | 类型 | 示例值 | 说明 |
|------|------|--------|------|
| `IMU.NoiseGyro` | float | 1.7e-04 | 陀螺仪噪声密度 (rad/s/sqrt(Hz)) |
| `IMU.NoiseAcc` | float | 2.0e-03 | 加速度计噪声密度 (m/s^2/sqrt(Hz)) |
| `IMU.GyroWalk` | float | 1.9393e-05 | 陀螺仪随机游走系数 |
| `IMU.AccWalk` | float | 3.e-03 | 加速度计随机游走系数 |
| `IMU.Frequency` | float | 200.0 | IMU 采样频率 (Hz) |
| `IMU.fastInit` | int | 1 | 快速 IMU 初始化开关。1=启用，跳过加速度检查，加快初始化 |

### 1.5 ORB 特征提取参数

| 参数 | 类型 | 示例值 | 说明 |
|------|------|--------|------|
| `ORBextractor.nFeatures` | int | 10000 | 每帧图像提取的 ORB 特征点数量。越多越鲁棒但计算量越大 |
| `ORBextractor.scaleFactor` | float | 1.2 | 图像金字塔层间尺度因子。1.2 表示每层缩放 1.2 倍 |
| `ORBextractor.nLevels` | int | 1 | 金字塔层数。1=单尺度，8=多尺度。使用 SuperPoint 时设为 1 |
| `ORBextractor.iniThFAST` | int | 20 | FAST 角点检测初始阈值。值越小检测到的角点越多 |
| `ORBextractor.minThFAST` | int | 7 | FAST 角点检测最小阈值。当 iniThFAST 检测不到足够点时降低到此值 |

### 1.6 可视化参数

| 参数 | 类型 | 示例值 | 说明 |
|------|------|--------|------|
| `Viewer.KeyFrameSize` | float | 0.05 | 关键帧在 3D 视图中的显示大小 |
| `Viewer.KeyFrameLineWidth` | float | 1.0 | 关键帧线框线宽 |
| `Viewer.GraphLineWidth` | float | 0.9 | 共视图边线宽度 |
| `Viewer.PointSize` | float | 2.0 | 地图点显示大小 |
| `Viewer.CameraSize` | float | 0.08 | 当前相机显示大小 |
| `Viewer.CameraLineWidth` | float | 3.0 | 当前相机线框线宽 |
| `Viewer.ViewpointX/Y/Z` | float | 0.0, -0.7, -1.8 | 默认视角位置 |
| `Viewer.ViewpointF` | float | 500.0 | 视角焦距 |
| `Viewer.imageViewScale` | float | 1.0 | 图像显示缩放比例 |

## 二、Gaussian Mapper 配置文件

Gaussian Mapper 配置文件控制 3D Gaussian Splatting 建图模块的行为。

### 2.1 模型参数 (Model)

#### 基础模型参数
| 参数 | 类型 | 示例值 | 说明 |
|------|------|--------|------|
| `Model.sh_degree` | int | 3 | 球谐函数最高阶数。0=漫反射，3=最大细节。影响颜色表达能力和计算量 |
| `Model.resolution` | float | -1.0 | 模型分辨率。-1.0 表示自动根据场景计算 |
| `Model.white_background` | int | 0 | 是否使用白色背景。0=黑色背景，1=白色背景 |
| `Model.eval` | int | 0 | 评估模式开关。1=启用评估模式，会输出更多评估指标 |

#### Anchor (锚点) 参数
| 参数 | 类型 | 示例值 | 说明 |
|------|------|--------|------|
| `Model.feat_dim` | int | 32 | 特征维度。锚点特征的向量维度 |
| `Model.n_offsets` | int | 10 | 每个锚点的偏移数量。控制每个锚点可生成的高斯数量 |
| `Model.voxel_size` | float | 0.001 | 体素大小。用于空间离散化，<=0 表示使用 1-NN 距离 |
| `Model.update_depth` | int | 3 | 更新深度。层次化更新的深度级别 |
| `Model.update_init_factor` | int | 16 | 初始更新因子。控制初始更新范围 |
| `Model.update_hierachy_factor` | int | 4 | 层次更新因子。控制层次间更新范围的比例 |

#### 外观与颜色参数
| 参数 | 类型 | 示例值 | 说明 |
|------|------|--------|------|
| `Model.use_feat_bank` | int | 0 | 是否使用特征库 |
| `Model.appearance_dim` | int | 0 | 外观嵌入维度。0=禁用外观建模，>0=启用 |
| `Model.lowpoly` | int | 0 | 低多边形模式。1=启用简化模型 |
| `Model.ds` | int | 1 | 下采样因子 |
| `Model.ratio` | int | 1 | 输入点云采样比例 |
| `Model.undistorted` | int | 0 | 是否使用去畸变图像 |
| `Model.embedding_dim` | int | 200 | 嵌入维度 |

#### 分布增强参数 (BungeeNeRF 数据集建议启用)
| 参数 | 类型 | 示例值 | 说明 |
|------|------|--------|------|
| `Model.add_opacity_dist` | int | 0 | 是否添加不透明度分布。适用于大视角变化场景 |
| `Model.add_cov_dist` | int | 0 | 是否添加协方差分布 |
| `Model.add_color_dist` | int | 0 | 是否添加颜色分布 |

### 2.2 相机与深度参数

| 参数 | 类型 | 示例值 | 说明 |
|------|------|--------|------|
| `Camera.z_near` | float | 0.01 | 相机近裁剪面 (米)。小于此值的点被裁剪 |

## 三、常用参数调整建议

### 3.1 提高建图质量

| 参数 | 建议值 | 说明 |
|------|--------|------|
| `Model.sh_degree` | 3 | 使用最大阶数获得最佳颜色细节 |
| `Optimization.max_num_iterations` | 60000 | 增加训练迭代次数 |
| `Mapper.min_num_initial_map_kfs` | 40~80 | 确保有足够的关键帧初始化 |

### 3.2 提高运行速度

| 参数 | 建议值 | 说明 |
|------|--------|------|
| `ORBextractor.nFeatures` | 5000 | 减少特征点数量 |
| `Optimization.max_num_iterations` | 15000 | 减少训练迭代次数 |
| `Model.sh_degree` | 1 | 降低球谐函数阶数 |
| `Record.record_rendered_image` | 0 | 关闭图像记录 |

### 3.3 处理大场景

| 参数 | 建议值 | 说明 |
|------|--------|------|
| `Model.voxel_size` | 0.01~0.05 | 增大体素大小，减少锚点数量 |
| `Optimization.densify_grad_threshold` | 0.0005 | 提高稠密化阈值，减少高斯数量 |
| `Mapper.cull_keyframes` | 1 | 启用关键帧剔除 |

### 3.4 处理动态场景

| 参数 | 建议值 | 说明 |
|------|--------|------|
| `Optimization.lambda_dssim` | 0.3~0.5 | 增加 DSSIM 权重，提高感知质量 |
| `Mapper.large_rotation_threshold` | 15.0 | 提高大旋转阈值 |
| `Mapper.large_translation_threshold` | 0.2 | 提高大平移阈值 |

## 五、注意事项

1. **相机参数必须与数据集匹配**：ORB_SLAM3 的相机内参必须与使用的数据集一致
2. **学习率调整需要谨慎**：过大的学习率会导致训练不稳定，过小会导致收敛慢
3. **内存占用**：`Model.sh_degree` 和 `Model.feat_dim` 越大，显存占用越高
4. **迭代次数**：`Optimization.max_num_iterations` 影响训练时间和最终质量
5. **关键帧数量**：`Mapper.min_num_initial_map_kfs` 过小会导致地图初始化失败
