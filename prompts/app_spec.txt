<project_specification>
  <project_name>SPGS-SLAM - SuperPoint + Gaussian Splatting SLAM</project_name>
  
  <overview>
    SPGS-SLAM is a real-time visual SLAM system that combines:
    - Frontend: Rover-SLAM with SuperPoint feature extraction (using ONNX Runtime)
    - Backend: SEGS-SLAM with 3D Gaussian Splatting rendering
    
    The system uses a Pull-Based integration mode where GaussianMapper (backend thread)
    actively pulls data from ORB-SLAM3's Atlas map system, ensuring thread-safe
    data access using mutex locks.
    
    Current status: The project has completed architecture research, code copying,
    CMake configuration, and DBoW3 integration. All dependencies are installed
    and the project compiles successfully.
  </overview>

  <architecture>
    <main_components>
      <frontend_rover_slam>
        <tracking_thread>
          - TrackMonocular(): Main tracking loop
          - SPextractor: SuperPoint feature extraction
          - Frame: Single frame representation
          - KeyFrame: Keyframe management
        </tracking_thread>
        <local_mapping_thread>
          - KeyFrame insertion and culling
          - MapPoint creation and fusion
          - Local bundle adjustment
        </local_mapping_thread>
        <loop_closing_thread>
          - Loop detection using DBoW3
          - Loop correction and optimization
          - Global bundle adjustment
        </loop_closing_thread>
        <atlas>
          - Multi-map management
          - Map switching and merging
          - GetCurrentMap(): Get active map
        </atlas>
      </frontend_rover_slam>
      
      <backend_segs_slam>
        <gaussian_mapper_thread>
          - Pull-Based data access from Atlas
          - GaussianModel: 3D Gaussian representation
          - GaussianScene: Scene graph management
          - GaussianRenderer: CUDA rasterization
          - Training loop with PyTorch optimization
        </gaussian_mapper_thread>
        <gaussian_model>
          - Anchor points (3D positions)
          - Scaling and rotation parameters
          - Opacity and color
          - MLP networks for appearance
        </gaussian_model>
        <viewer>
          - ImGui-based visualization
          - Real-time rendering
          - Interactive camera controls
        </viewer>
      </backend_segs_slam>
    </main_components>
    
    <integration_mode>Pull-Based</integration_mode>
    <description>
      GaussianMapper actively pulls data from ORB-SLAM3's Atlas:
      1. Check if minimum KFs threshold met (15 KFs)
      2. Lock map with mMutexMapUpdate
      3. Get all KeyFrames and MapPoints
      4. Extract 3D positions and colors
      5. Cache points in GaussianScene
      6. Unlock and train for one iteration
    </description>
  </architecture>
